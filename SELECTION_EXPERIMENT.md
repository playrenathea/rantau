# MVP: Zone + Location Selection Laboratory

This is an intentionally temporary content-selection experiment (v0.1.0-selection). The original mobile UI skin, Hold/Don't Tap onboarding, gesture mechanics and 3-tab footer are retained; the Location tab shows only lists of selected Zones and Locations, not spatial travel. The Interaction tab has no NPCs. Existing users keep the same localStorage key `infaction-mvp-01`; intro appears only for fresh state or explicit Return to intro. Reload resumes active selection stage/seed. New universe regenerates selections. Previous spatial generator remains in `place-generator.js` and `world-place-generator.js` but is not used for selection rendering.

## Algorithm

126 Place Types, global uniqueness; Zone pool Scale 4–5, Location pool Scale 1–2, fixed triangular counts 6–9/20–30. Initial anchor in **each** pool is Authority × actual Government faction including its second Type and Base. Later select Function with greatest universal demand minus normalized raw-A supply (relative Function demand 4,4,2,2,1,2), and Faction with greatest demand minus normalized raw-A supply (six actual factions equal, Neutral=1 provisional). Each candidate uses `(F+A+sqrt(F*A)+R)/4`, where F and A are precomputed B effective affinities /100. Faction Type(s) and Base combined as geometric mean. Highest score wins; all raw-A normalized supply contributions accumulate independently within each role. No placement, Site, visibility, geography, mandatory Location, or spatial affinity scoring yet.

## Data and experiment controls

Editable native spreadsheet: https://docs.google.com/spreadsheets/d/1uxvNhDWZJ5w6jrWJzsT6vr4vvd5wkkIa_TNQMK9x6fI/edit . Three new tabs: `Selection - Function A` (provisional grouping of legacy 15 functions via maximum affinity, 0–100), `Selection - Function B` (formulas from A + old Bias), and `Selection - Controls` (A→B weights and demand). Existing faction Type+Neutral and Base A remain editable source tabs. Default A→B weights [1,0,0,0,0] make B=A; bias archived until enabled. Geography and Visibility endpoints are parked. **The standalone browser runtime uses an embedded snapshot/default settings; changing the spreadsheet does not auto-sync the GitHub data or update the live MVP.** For reproducible tuning, update the source snapshot and controls when publishing a new experiment; do not claim live spreadsheet sync.
