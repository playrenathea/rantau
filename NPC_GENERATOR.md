# Gate NPC Population v0.1.0
Source: Infaction_NPC_Affinity_Gate_v0.2.xlsx, eight enabled archetypes, averaged directional weights and active label rows. No timing modifier. Each actual faction gets mean of per-type cube-root(LA*LF*AF)*sparse booster; Guard restricted to controlling Government faction in Gate prototype. Draw 3–5 uniformly (provisional), retain pinned NPCs, draw with replacement and 0.5^existing archetype count. Label highest average of mean type score and base score; filter zero type nonfallback; tie type, base, generic fallback, alphabetical. Generic label displayed as name, archetype remains canonical key. No hard cap, no mandatory guard, no non-faction population yet. Existing Gate actions use canonical Visitor/Infiltrator instead of old Traveler/Smuggler strings. Other archetypes do not yet gain custom actions. Existing worlds retain state except NPC population refresh once on schema migration. Sample test 3000 worlds, count/affiliation/label invariants passed; no browser test.
