# Infaction — political dominance experiment (5 percentage points)

Status: EXPERIMENTAL, not a v0.4.8 design lock. Uses original Book1 Faction Type/Base affinity and Neutral static v2, *not* Containment. Run after the world Place generation is completed. Never alter Location→Zone placement when recalculating ownership.

## Calculation

For Faction F with Types T1,T2 and Base B (if single Type, T2=T1), raw Faction affinity:
`R = 0.5 * [(T1+T2+B)/3 + cuberoot(T1*T2*B)]`.
Neutral uses `data/infaction_neutral_static_v2_locked.json`.

In the union of all Zone + Site + Location Places in the world, normalize raw per-Place (A) and per-Faction/Neutral-column then per-Place (B), each to 100%; calculate 50% A + 50% B. **Only after** this original 100% distribution, apply:
`P'[i] = 0.95 * P[i] + (5 if i == explicitly_selecting_faction else 0)`.
Only for a Place with an explicit Faction selector, Neutral and all other Factions are also reduced to 95%. For Sites and Zone/Location without a selecting Faction, the original 100% vector is unchanged. This is 5 **percentage points** (not a relative 5% multiplier). `selected_by` for a Zone and `stage=faction; parts.faction` for a Location are authoritative. Locations selected by Zone or supplemental receive **no** selection bonus. Sites receive no selection bonus, as they are generated by greedy grouping, not selected by Faction.

Run Single/Dual tests **after the bonus**. Locked Zone: Single top≥32, lead≥7, top>Neutral; Dual top≥26, second≥19, top−second≤8, second−third≥3, second>Neutral. Locked Location: same but Single top≥28 and Dual top≥23. Site thresholds are **not yet locked**; this experiment provisionally uses the Location thresholds. None means neither rule passes; being selected by a Faction does NOT guarantee ownership.

## One-world calculation: seed 8100000

Used 8 Zones, 2 Sites (Meeting Hall, Grounds), 23 Locations = **33 political Place rows**. Original master snapshot, locked Neutral v2, and original 50:50 A/B used. No missing source affinity in this seed. Outcome after 5pp: **5 Single, 1 Dual, 27 None**.

- Government District → Single F1, selector F1: 39.51448 → 42.53876.
- Enclave → Dual F3+F4, selector F3: 26.88095 → 30.53690 for F3.
- Archive → Single F1, selector F1: 30.01149 → 33.51091.
- Fortress → Single F2, selector F2: 26.80424 → 30.46403.
- Camp → Single F4, selector F4: 27.12893 → 30.77248.
- Brewery → Single F5, selector F5: 26.33208 → 30.01548.
- Meeting Hall Site → None, no selector.
- Grounds Site → None, no selector.

They were omitted from the narrower Zone/Location selection maps, not absent from Book1. The eight full original rows have been recovered losslessly into [`data/infaction_missing_8_place_affinity_book1_recovered.json`](../data/infaction_missing_8_place_affinity_book1_recovered.json). The MASTER spreadsheet contains a `Recovered Scale 3 (8)` audit tab, and the original full records remain in `Book1 Place Affinity`. **Only Neutral *static v2* calibrated values remain uncurated** for those eight (the original Book1 Neutral is not identical to static v2); the recovery contains their formula-derived no-context baseline, not a new locked Neutral v2 replacement. Political experiments must not silently equate the original Neutral scores with static v2.
